01 / 功能

简单到只有一次点击

没有账号、没有预测模型、历史数据不参与选号。该有的小细节都做了。

◉

双玩法切换

双色球 33 选 6 + 16 选 1，大乐透 35 选 5 + 12 选 2，规则常量只定义一次。

✦

一键生成 5 注

号码球滚动开奖动画，每次结果独立随机，同区号码不重复且升序排列。

◧

复制与快捷键

复制单注 / 复制全部 / 清空，空格或回车即可再生成一轮。

▤

号码热度

汇总本次会话各号码出现频次，纯娱乐观察，不暗示任何趋势。

⊘

离线选号 · 开奖可更新

选号来自本地系统熵源、全程无网络请求；桌面端另可在启动时联网刷新开奖数据，失败自动回退缓存或内置快照。网页版降级为 Web Crypto 随机并使用内置快照。

◇

三平台客户端

Tauri 2.0 + Rust 后端，Windows / macOS / Linux 均有安装包，由 GitHub Actions 自动发布。

02 / 玩法

号码怎么来的

对 1..N 做部分 Fisher-Yates 洗牌，取前若干个后升序排列 —— 等概率、不放回。

玩法前区后区单注
双色球01–33 选 6 红球01–16 选 1 蓝球6 + 1
大乐透01–35 选 5 前区01–12 选 2 后区5 + 2

规则、抽样与边界校验都有 Rust 单元测试覆盖。网页版使用同一套规则，随机数改由浏览器本地生成。客户端侧栏展示最近 10 期官方开奖号码：桌面端由 Rust 侧联网更新并缓存，网页版使用定时抓取的内置快照，均仅供查阅、不参与选号。
